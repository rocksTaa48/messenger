# Messenger

To start your Phoenix server:

* Run `mix setup` to install and setup dependencies
* Start Phoenix endpoint with `mix phx.server` or inside IEx with `iex -S mix phx.server`

Now you can visit [`localhost:4000`](http://localhost:4000) from your browser.

Ready to run in production? Please [check our deployment guides](https://hexdocs.pm/phoenix/deployment.html).

## Общая информация
Это чат между пользователем и AI внутри Telegram Messenger, Telegram Mini App.
В качестве провайдера выступает OpenRouter.
Пользователь получает доступ к n количеству моделей в зависимости от своего плана.
Предусмотрен как бесплатный доступ так с ограничениями, так и приоритетный, 
после внесения некоторого депозита. Тогда он получает доступ к большому списку моделей.
Тарификация осуществляется в условных еденицах, для оплаты мощностей поставщиков услуг.
### Некоторые общие детали
Реализована классическая система чата, когда пользователь открывает новое окно переписки,
и как только он отправляет сообщение, создается текущий чат с AI моделью, которая продолжает
сохранять контекст беседы в текущем чате. Дополнительно в настройках можно подключить
обьединение контекста по всем чатам, для создания некоторого образа пользователя в RAG.
Так же присутствует уже готовый набор агентов в пункте Agents которые имеют преднастройки,
Skills для помощи пользователю. Например обучение языку (Английский, Немецкий,
Испанский, Французский, и.т.д), или ментора по математике или физике. Что безусловно
удобно для бастрого диалога с уже настроенной моделью.
